# Требования

Источник требований — техническое задание TrayX (Windows System Tray Enhancement).

Ключевые инварианты:

- реальная интеграция с Windows, а не визуальная имитация;
- сохранение штатной функциональности системы;
- никаких патчей Explorer, инъекций DLL и изменений системных файлов как основы;
- каждая кнопка и переключатель выполняют реальное действие;
- при недоступности API — безопасная альтернатива и честно задокументированное ограничение;
- модульность: сбой одного модуля не отключает остальные;
- низкая нагрузка, отсутствие постоянного опроса и утечек памяти;
- установщик, обновления, тесты и документация — часть готового продукта.

Детализация по функциям будет переноситься сюда по этапам; архитектурные решения — в [docs/Architecture](../Architecture/overview.md).
