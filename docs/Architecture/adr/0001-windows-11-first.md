# ADR-0001: Windows 11 first, Windows 10 later

- Статус: принято
- Дата: 2026-10-31

## Контекст

TrayX глубоко интегрируется с оболочкой Windows: трей, уведомления, дисплеи, аудио. Windows 10 и Windows 11 различаются реализацией панели задач, DPI-масштабированием и поведением системного трея. Поддержка обеих версий с первого дня увеличивает объём ветвлений и замедляет разработку.

## Решение

Сначала реализуется качественная версия для Windows 11 22H2+ (`net10.0-windows10.0.22621.0`). Весь платформенный код изолируется в `TrayX.Windows`; Domain и Application остаются независимыми от версии ОС. Через интерфейсы предусматриваются точки расширения для будущего адаптера Windows 10.

## Последствия

- Меньше legacy-кода и проверок версий на старте.
- Приложение не запускается на Windows 10 до появления отдельного адаптера.
- Любая новая системная зависимость проверяется на совместимость с будущей поддержкой Windows 10.
- Целевая версия меняется в одном месте — `Directory.Build.props`.
