# Ограничения TrayX

Этот документ пополняется при реализации и ручной проверке функций.

| Область | Ограничение | Обходной путь / статус |
|---|---|---|
| Системный трей | TrayX не заменяет штатную панель задач и не внедряется в Explorer. Доступ к значкам сторонних приложений зависит от доступных интерфейсов Windows UI Automation. | TrayX дополняет Windows; недоступные элементы остаются под управлением Windows. |
| Скрытые значки | Перечисление скрытых значков зависит от того, открыта ли штатная область переполнения. | Открывать штатную область через панель TrayX. |
| Панели мониторов | Панель на дополнительном дисплее — отдельное окно TrayX, а не полноценная копия системной панели задач. | Проверить на физической конфигурации с несколькими экранами перед заявлением полной поддержки. |
| Звуковые устройства | Регулировка доступна только устройствам, предоставляющим endpoint volume interface. Переключение устройства по умолчанию использует Windows Audio Policy COM API, который не является документированным публичным API Windows. | При недоступности интерфейса TrayX открывает параметры звука Windows; проверить переключение на поддерживаемых версиях Windows вручную. |
| Аудиосессии | Сессии берутся с текущего устройства вывода; появление, громкость, Mute, состояние и закрытие отслеживаются Core Audio callbacks. | Ручная проверка внешнего Windows-модулятора и быстрого создания/закрытия сессий ещё не пройдена. |
| Peak meter | Уровень чтения микрофона запрашивается у Core Audio с частотой 10 Гц только пока открыт Audio Center; endpoint без `IAudioMeterInformation` не показывает индикатор. | Это индикатор уровня, не запись и не сохранение аудио. |
| Маршрутизация приложений | TrayX не переназначает устройство конкретной аудиосессии напрямую; кнопка открывает штатную страницу маршрутизации приложений Windows. | Настроить маршрутизацию через `ms-settings:apps-volume`. |
| Иконки устройств/сеансов | Для endpoint используется общая пиктограмма ввода/вывода, не индивидуальный значок производителя. Значок сессии берётся из пути процесса, если Windows его предоставляет. | Имена и реальные уровни/состояния доступны независимо от наличия индивидуального значка. |
| Быстрые параметры Windows | Для ряда действий приложение открывает страницу Windows Settings вместо прямого переключения системного параметра. | Это поведение должно быть явно обозначено в UI. |
| История уведомлений | Хранятся только уведомления TrayX, переданные через внутренний IPC; системные уведомления Windows и уведомления сторонних приложений не перехватываются. Хранится не более 1000 последних записей. | Просмотр и очистка доступны в Control Center; фактическое системное уведомление Windows по-прежнему зависит от оболочки. |
| Приложения в трей | Автоскрытие выключено по умолчанию и требует отдельного включения для Tray Apps и каждого правила. Скрытие не создаёт значок в штатной области уведомлений Windows; в Tray Strip отображается не более 20 последних скрытых окон. Если процесс недоступен, восстановление остаётся в журнале; owned windows и окна процессов с более высоким уровнем прав отклоняются при скрытии. | Восстановите окно из строки в Control Center, подменю значка TrayX или кнопки на панели дополнительного монитора; для массового восстановления используйте «Восстановить все». |
| Windhawk | Сторонние моды могут внедрять код в процессы Windows и ломаться после обновлений ОС; каталог и совместимость меняются. TrayX не устанавливает, не запускает и не настраивает Windhawk. | Проверяйте актуальные сведения и предупреждения на официальной странице мода; рекомендации в TrayX — ссылки, а не гарантия поддержки. |
| Звуковые события | Пользовательский WAV поддерживается только для смены устройства вывода по умолчанию; принимаются абсолютные локальные пути, UNC/device paths и mapped network drives не поддерживаются. Формат WAV, сохранность файла и доступность его пути необходимы для воспроизведения. | При недоступном файле TrayX записывает предупреждение и использует системный сигнал Windows. |
| Автоматизация | Поддерживается одно ежедневное локальное расписание для выбранного профиля; правила по приложениям, событиям, дням недели и несколько параллельных расписаний пока не реализованы. Пропущенное во время сна время не восполняется. Если аудиоустройство недоступно или аудионастройки не применяются, тема и акцент применяются отдельно, а интерфейс сообщает о частичном результате. | Расписание проверяется Core с интервалом до 15 секунд и срабатывает не более одного раза в локальную календарную дату; проверить его вручную после сохранения. |
| Совместимость | Целевая система — Windows 11 22H2+ (build 22621+) и .NET 10 SDK. | Другие версии Windows не заявлены как поддерживаемые. |
