# Карта пользовательских настроек

Сопоставление настроек, которые сейчас хранятся в `TrayXSettings`, с фактическим эффектом. Проверка сборки подтверждает компиляцию, но не заменяет ручную проверку влияния на Windows.

| Поле | Что меняет | Проверка |
|---|---|---|
| `ConfigVersion` | Версия формата JSON; при загрузке старые и неверсионированные настройки нормализуются до текущей версии, новые поля получают значения по умолчанию | Unit: `DeserializingLegacySettings_UsesCurrentConfigVersion`, `DeserializingVersionOneSettings_AddsFavoriteDeviceSetting`, `Normalize_UpgradesUnversionedSettings` |
| `TrayAppsAutoHideEnabled`, `TrayAppRules[].AutoHide` | Двойное opt-in для автоскрытия: общая настройка и настройка каждого правила; оба выключены по умолчанию. При выключении общего параметра Core восстанавливает только окна, автоматически скрытые правилами. | Unit: `TrayAppsAutoHide_IsDisabledByDefault`, `TrayAppRules_SurviveConfigurationSerialization`; integration: `TrayAppsModule_AutoHidesOnlyWithMasterAndRuleOptIn_AndRestoresOnlyAutomaticWindowsWhenDisabled` |
| `ThemeMode` | Тема интерфейса TrayX: светлая, тёмная или системная | Ручная: сменить режим и проверить страницы, меню и повторный запуск |
| `Accent` | Акцентный цвет UI; профиль также сохраняет и применяет цвет | Unit: `Normalize_KeepsTheLiveSwitchAndOtherFields`; ручная проверка нескольких цветов и перезапуска |
| `Language` | Локализация UI, текст значка и меню TrayX, панели дополнительных экранов | Unit: `Normalize_KeepsTheLiveSwitchAndOtherFields`; `LocalizationTests` проверяет согласованность RU/EN словарей; ручная проверка смены языка во время работы |
| `ClockFormat` | Формат часов Quick Panel и панелей дополнительных экранов: системный, 12- или 24-часовой | Unit: `FormatClockTime_UsesSelectedFormat`, версия 2 мигрируется на системный формат; ручная: переключить режим и проверить панели/перезапуск |
| `ScheduledProfileId`, `ScheduledProfileTime` | Один профиль автоматически применяется ежедневно в заданное локальное время, даже если окно UI закрыто; удаление выбранного профиля отключает расписание | Unit: нормализация времени и JSON round-trip; ручная: выбрать профиль, установить ближайшую минуту, проверить применение при закрытом UI и отключение |
| Календарь Quick Panel | Показывает сетку месяца, позволяет перемещать месяц, выбирать дату, возвращаться к текущей дате и открывать страницу даты/времени Windows | Реализовано в Quick Panel; ручная проверка RU/EN, границ месяца и перехода к Windows Settings |
| `LaunchAtStartup` | Добавляет или удаляет регистрацию запуска TrayX.Core для текущего пользователя | Ручная: переключить, проверить фактическую запись запуска и вход в Windows |
| `OpenDashboardOnStartup` | Открывает Control Center при старте Core | Ручная: проверить оба значения после перезапуска Core |
| `TrayIconEnabled` | Добавляет/удаляет собственный значок TrayX через `Shell_NotifyIcon` | Ручная: переключить настройку и проверить значок, в том числе после перезапуска Explorer |
| `TrayLeftClickAction` | Определяет действие по левому клику: панель, обзор или переключение Mute | Нормализация ограничивает допустимые значения; ручная проверка каждого действия |
| `ShowTrayNotifications` | Разрешает/запрещает системные balloon-уведомления TrayX и уведомления об аудиоустройствах | Ручная: подключить/отключить аудиоустройство при обоих значениях |
| `PlayDeviceSounds`, `DeviceSoundPath` | Включает звуковой сигнал при смене default audio device; можно выбрать WAV, проверить воспроизведение или сбросить к сигналу Windows | Путь сохраняется в JSON; ручная: выбрать корректный WAV, проверить preview и реальную смену устройства, проверить fallback при удалённом/некорректном файле |
| История уведомлений | Хранит до 1000 уведомлений TrayX в SQLite; список можно просматривать и очищать в Control Center | Интеграционный тест проверяет сохранение, сортировку и очистку; ручная проверка уведомлений после перезапуска |
| `MonitorIntervalMs` | Интервал обновления показателей страницы «Система» | Нормализация ограничивает 500–10000 мс; ручная: сравнить частоту обновления при разных значениях |
| `TrayLiveEnabled` | Включает/отключает чтение живых значков через UI Automation; на панелях мониторов при выключении очищается список значков | Unit: `Normalize_KeepsTheLiveSwitchAndOtherFields`; ручная: переключить при открытом Control Center и на дополнительном экране |
| `TrayLivePollMs` | Интервал повторного сканирования UI Automation и обновления снимка трея | Unit: `Normalize_ClampsLivePollInterval`; ручная: сверить обновление значков при подключении/закрытии приложения |
| `DisabledTrayPanelDisplays` | Список дисплеев, для которых отключено окно панели TrayX; хранит PnP ID, распознаёт старые имена `DISPLAYn` | Unit: `Normalize_RemovesDuplicateAndEmptyDisabledDisplays`, `DisabledTrayPanelDisplayIds_SurviveConfigurationSerialization`; интеграционный тест проверяет непустые уникальные ID подключённых дисплеев; ручная: переставить мониторы и проверить привязку |
| `FavoriteAudioDeviceIds` | Сохраняет список избранных аудиоустройств и их состояние в Audio Center | Unit: нормализация и сериализация избранных устройств; ручная: добавить/удалить устройство и перезапустить TrayX |
| Импорт конфигурации | Полностью заменяет настройки выбранным JSON после подтверждения; данные нормализуются, будущие версии и файлы больше 1 МБ отклоняются | Unit: round-trip, ошибочные JSON и будущая версия; ручная: импорт и проверка работы автозапуска/Runtime |
| Экспорт конфигурации | Сохраняет текущие настройки в JSON-файл | Unit: round-trip настроек; ручная: экспортировать, изменить значения, импортировать файл |
| Сброс настроек | Заменяет текущие настройки значениями по умолчанию; профили SQLite и журналы не удаляются | Ручная: сбросить настройки и убедиться, что профили остались |

Настройки сохранены в `%APPDATA%\TrayX\config.json`. В UI доступны импорт и экспорт JSON-конфигурации и сброс настроек к значениям по умолчанию. Экспорт не включает SQLite-профили и журналы; импорту файлов больше 1 МБ или конфигурации от более новой версии отказано. Сброс сохраняет профили и не удаляет журналы.
