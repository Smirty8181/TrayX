# Матрица быстрых настроек

Правило: плитка либо меняет состояние через TrayX и показывает прочитанное состояние, либо явно открывает соответствующую страницу Windows Settings. Переход на страницу Windows не является переключением параметра.

| Параметр | Текущая реализация | Источник состояния / место управления |
|---|---|---|
| Громкость вывода | Меняем напрямую; Mute и уровень вызывают Audio Center | Core Audio endpoint, отображается в Quick Panel и Audio Center |
| Устройство вывода | Прямой выбор устройства по умолчанию | Audio Center; Windows Audio Policy API с описанным ограничением |
| Устройство ввода | Прямой выбор устройства по умолчанию | Audio Center; Windows Audio Policy API с описанным ограничением |
| Громкость и Mute микрофона | Прямой контроль доступен в Audio Center, не отдельной плиткой Quick Panel | Core Audio endpoint; доступность зависит от endpoint |
| Яркость | Меняем напрямую, когда дисплей сообщает поддерживаемый уровень | DisplayService; Quick Panel показывает ползунок основного дисплея |
| Тема Windows | Меняем напрямую | WindowsThemeService; состояние перечитывается из системных параметров |
| Wi-Fi | Открываем Параметры → Сеть и Интернет → Wi-Fi; радио из TrayX не переключаем | `ms-settings:network-wifi`; состояние контролирует Windows |
| Bluetooth | Открываем Параметры → Bluetooth | `ms-settings:bluetooth`; состояние контролирует Windows |
| Авиарежим | Открываем страницу авиарежима Windows | `ms-settings:network-airplanemode`; состояние контролирует Windows |
| Приватность микрофона | Открываем системные разрешения микрофона; глобальное разрешение не переключаем из TrayX | `ms-settings:privacy-microphone` |
| Приватность камеры | Открываем системные разрешения камеры; глобальное разрешение не переключаем из TrayX | `ms-settings:privacy-webcam` |
| Энергопитание | Открываем системные параметры питания | `ms-settings:powersleep` |
| Экономия энергии | Открываем системные параметры питания; режим напрямую не переключаем | `ms-settings:powersleep` |
| Ночной свет | Открываем страницу ночного света; режим напрямую не переключаем | `ms-settings:nightlight` |
| Фокус / «Не беспокоить» | Открываем системные параметры уведомлений; режим напрямую не переключаем | `ms-settings:notifications` |
| Уведомления Windows | Открываем системные параметры уведомлений | `ms-settings:notifications` |
| Дисплеи | Открываем страницу мониторов TrayX для яркости и конфигурации, при необходимости — параметры Windows | Control Center → Мониторы / `ms-settings:display` |
| Звук | Открываем Audio Center TrayX, системные параметры остаются доступны из Audio Center | Audio Center / `ms-settings:sound` |

Quick Panel показывает локализованное общее пояснение: перечисленные действия открывают системные параметры и не переключают состояние напрямую. Доступность конкретной страницы `ms-settings:` зависит от версии Windows, редакции ОС и оборудования; список URI основан на [документации Microsoft](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-settings). Переходы и фактическую доступность следует проверять вручную на поддерживаемой Windows 11.
