# API

Внутренние контракты TrayX документируются здесь по мере появления стабильных интерфейсов:

- IPC-команды и события между UI и Core;
- интерфейсы платформенных сервисов (`TrayX.Windows`);
- репозитории и миграции (`TrayX.Storage`);
- контракты модулей.

Публичного HTTP API у приложения нет и не планируется.
