# TrayX.Modules

Функциональные модули Core. Каждый модуль реализует `TrayX.Application.Modules.ITrayXModule`, имеет собственные настройки, проверку доступности, обработку ошибок и логирование.

| Каталог | Модуль |
|---|---|
| `TrayManager` | обнаружение, сортировка и управление значками |
| `AudioCenter` | громкость, устройства вывода и микрофоны |
| `SoundEvents` | пользовательские звуки системных событий |
| `QuickSettings` | Wi-Fi, Bluetooth, яркость, питание |
| `MultiMonitor` | независимые конфигурации для каждого дисплея |
| `SystemMonitor` | CPU, RAM, GPU, сеть, диски, батарея |
| `Automation` | правила «событие → условие → действие» |

Сбой одного модуля не должен останавливать остальные и весь Core.
