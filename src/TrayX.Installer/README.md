# Установщик TrayX

Установщик пока не реализован: каталог содержит только этот план и не является проектом сборки. TrayX запускается из собранных проектов; обновление и установка через пакет не поддерживаются.

План:

- WiX Toolset 6 + Burn Bootstrapper;
- единый x64 bootstrapper;
- выбор компонентов, каталога и автозапуска;
- обновление поверх предыдущей версии с сохранением `%AppData%\TrayX`;
- откат при неудачном обновлении;
- цифровая подпись и проверка целостности;
- корректное удаление без остатков в системе.

Каталог намеренно не включён в solution, поэтому обычные restore/build/test команды не требуют WiX и Windows Installer tooling. Перед выпуском установщик, обновление, откат, подпись и удаление необходимо реализовать и проверить отдельно.
